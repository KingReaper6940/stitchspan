# Practice swatch

An invented arithmetic example, not a complete knitting pattern.

Run `npm run example` to regenerate:

- `project.json`: reopenable settings and notes.
- `plan.txt`: complete source-position instructions and output ranges.
- `changes.csv`: all seven KFB events.
- `report.json`: complete independent count receipt.
- `plan.html`: standalone text, map and event table.
- `source-map.svg`: actual generated count diagram, not an application screenshot.

Start 78, target 85, flat KFB, protected edges 2 and 2. Seven shaping operations consume seven original stitches. The remaining 67 interior plain stitches are split into eight gaps: 8, 8, 9, 8, 8, 9, 8, 9. With four protected stitches, that consumes exactly 78 and produces 85.

No gauge, garment fit, physical knitting or stitch-pattern compatibility is implied.
